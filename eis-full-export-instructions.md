# Как получить полный массив контрактов ООО «Областной центр дезинфекции» из ЕИС

**Поставщик:** ООО «Областной центр дезинфекции»  
**ИНН:** `5021001371`  
**Закон:** 44-ФЗ  
**Цель:** получить воспроизводимый массив всех контрактов и документов для антимонопольного скрининга.

## 1. Основной официальный маршрут через ЕИС

ЕИС предоставляет свободный доступ к информации о контрактной системе и содержит отдельные разделы для поиска закупок, реестра контрактов и реестра недобросовестных поставщиков [1].

1. Откройте [расширенный поиск закупок ЕИС](https://zakupki.gov.ru/epz/order/extendedsearch/search.html).
2. В разделе **«Закон»** выберите **44-ФЗ**.
3. В блоке **«Участник закупки»** укажите ИНН поставщика `5021001371`. Если форма предлагает отдельный поиск организации, выбирайте юридическое лицо по ИНН, а не только текстовое совпадение названия.
4. Установите период с максимально ранней даты регистрации/первого участия по текущую дату. Не ограничивайте поиск только Московской областью: в рабочей выборке встречались закупки в других регионах.
5. Отдельно сохраните результаты для статусов **«Закупка завершена»**, **«Закупка отменена»** и других доступных этапов. Для анализа поведения важны не только победы.
6. Сохраните каждую карточку закупки и её реестровый номер. Внутри карточки скачайте разделы **«Документы»**, **«Протоколы»**, **«Изменения»**, **«Журнал событий»** и, если доступно, сведения об участниках.

Расширенный поиск ЕИС позволяет фильтровать по закону, цене, датам, заказчику, участнику, ИНН, ОКПД2, ОКВЭД2, предмету аукциона, ИКЗ и другим параметрам [1].

## 2. Проверка через реестр контрактов

Откройте [реестр контрактов ЕИС](https://zakupki.gov.ru/epz/contract/search/results.html). Ищите по ИНН поставщика, если форма поддерживает фильтр участника, и сверяйте каждый найденный контракт с реестровым номером закупки.

В карточке контракта необходимо сохранить цену, дату заключения, сроки, предмет, сведения об изменениях, вложения и электронные документы исполнения. ЕИС показывает ссылки на карточку закупки, документы контракта и электронные документы об исполнении [2].

Результат следует выгружать в две связанные таблицы:

| Таблица | Обязательные поля |
|---|---|
| `contracts.csv` | реестровый номер контракта, номер закупки, заказчик, ИНН заказчика, дата, предмет, НМЦК, цена контракта, статус, ссылка |
| `procurement_participants.csv` | реестровый номер закупки, участник, ИНН, допуск, причина отклонения, место, цена заявки, статус |
| `auction_steps.csv` | реестровый номер закупки, участник, время шага, цена шага, номер шага |
| `documents.csv` | реестровый номер, тип документа, дата публикации, URL, контрольная сумма файла |
| `execution.csv` | реестровый номер контракта, акт, сумма, дата исполнения, изменение, расторжение, отказ, неустойка |

## 3. Как получить именно ценовые предложения

Для картельного скрининга одной итоговой цены недостаточно. В каждой карточке нужно открыть **протоколы** и скачать документы, где отражены заявки, допуск, результаты и, для электронных процедур, порядок ценовых шагов. Названия документов могут различаться в зависимости от способа закупки и версии ЕИС.

Для каждого участника нужно отличать:

- цену первоначальной заявки;
- цену, поданную в ходе аукциона;
- последнюю цену участника;
- итоговую цену победителя;
- цену контракта после изменений.

Если ЕИС показывает только итоговый протокол, следует зафиксировать это как ограничение. Не следует реконструировать отсутствующие ставки по проценту снижения или по позиции участника.

## 4. Если интерфейс ЕИС не позволяет получить полный массив

Сформируйте обращение в техническую поддержку ЕИС через официальный интерфейс сайта. В обращении укажите, что нужен **не аналитический вывод**, а перечень публичных реестровых номеров и ссылки на опубликованные карточки по конкретному ИНН.

### Шаблон обращения

> Прошу разъяснить официальный способ получения полного перечня опубликованных сведений о контрактах по 44-ФЗ, где поставщиком указан ООО «Областной центр дезинфекции», ИНН 5021001371. Необходимы реестровые номера закупок и контрактов, ссылки на карточки ЕИС, сведения о НМЦК, цене контракта, участниках, протоколах, изменениях и исполнении за весь период публикации. Прошу указать, имеется ли официальный механизм массовой выгрузки, открытая документация API или допустимый формат запроса к публичным данным ЕИС. Запрос предназначен для воспроизводимого анализа открытых данных; персональные данные, не подлежащие публикации, не запрашиваются.

Отдельно можно направить запрос оператору электронной площадки, указанному в конкретной карточке. Оператору следует просить не закрытые персональные данные, а ссылки или порядок доступа к опубликованным протоколам и журналам торгов. Технические журналы и IP-данные обычно не являются общедоступной частью карточки и могут быть предоставлены только компетентному органу либо при наличии законного основания.

## 5. Проверка полноты выгрузки

После получения данных посчитайте уникальные реестровые номера и сравните их с заявленным количеством 232. Нужно отдельно показать:

| Контроль | Что проверяется |
|---|---|
| Дубликаты | один контракт не должен считаться несколько раз из-за изменений карточки |
| Закон | исключены 223-ФЗ и иные режимы, если исследуется только 44-ФЗ |
| Роль | поставщик, участник, победитель и заказчик не смешиваются |
| Период | дата публикации, заключения и обновления не подменяют друг друга |
| Цена | НМЦК, цена заявки, итоговая цена и цена исполнения хранятся раздельно |
| Статус | исполнение, расторжение, отказ и РНП подтверждаются документами |
| Документы | сохраняются URL, дата скачивания и хэш файла |

## 6. Что передать для полного анализа

Для полного анализа 232 контрактов достаточно передать архив с CSV/JSON и папкой документов либо таблицу с перечисленными полями. Минимально необходимы реестровый номер, НМЦК, цена контракта, все участники, цены заявок, протоколы и статусы исполнения. При наличии только списка контрактов и итоговых цен можно провести описательную статистику, но не полноценный анализ согласованных ценовых действий.
