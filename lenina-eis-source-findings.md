# Источники ЕИС для расширенной выгрузки

- Официальный расширенный поиск закупок: https://zakupki.gov.ru/epz/order/extendedsearch/search.html
- Официальная страница результатов поиска закупок: https://zakupki.gov.ru/epz/order/extendedsearch/results.html
- Официальный реестр контрактов 44-ФЗ: https://zakupki.gov.ru/epz/contract/search/results.html
- Руководство пользователя ЕИС найдено как дополнительный методический источник: https://s.pro-goszakaz.ru/files/portal/rukeis.pdf

В инструкции следует разделить «реестр закупок» и «реестр контрактов»: первая выдача нужна для поиска процедур и протоколов, вторая — для контрактов, изменений, исполнения и расторжений. Адресный поиск должен дублироваться поиском по заказчику, месту исполнения, ОКПД2/КТРУ и ключевым словам, поскольку адрес может быть указан в документации, а не в кратком названии закупки.
