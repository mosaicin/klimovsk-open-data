# Как получить расширенную выгрузку ЕИС по улице Ленина в Климовске

**Цель:** собрать максимально полный и воспроизводимый реестр закупок и контрактов по благоустройству, капитальному ремонту, дорогам, дворам, освещению, теплоснабжению и сетям на участке улицы Ленина в микрорайоне Климовск города Подольска.

**Официальные входы:** [расширенный поиск закупок ЕИС](https://zakupki.gov.ru/epz/order/extendedsearch/search.html), [результаты поиска](https://zakupki.gov.ru/epz/order/extendedsearch/results.html) и [реестр контрактов 44-ФЗ](https://zakupki.gov.ru/epz/contract/search/results.html).

## 1. Сначала определить адресную рамку

В отдельном файле зафиксируйте все варианты адреса:

| Тип | Варианты для поиска |
|---|---|
| Населённый пункт | Подольск; город Подольск; мкр Климовск; Климовск |
| Улица | улица Ленина; ул. Ленина; Ленина |
| Ориентиры | Фабрика игрушек; Фабричный проезд; АО «КЛИМО»; ДК «Машиностроитель»; Молодёжная, 11; «Глобус» |
| Адреса | Ленина, 1; 5; 7; 7А; 13; 20; 27; 46; 62 — уточнить фактический перечень домов по адресной карте |

Не ограничивайтесь одним полем поиска. Адрес может находиться в месте исполнения, техническом задании, приложении к контракту или протоколе, но отсутствовать в названии закупки.

## 2. Поиск в реестре закупок

В разделе расширенного поиска установите закон **44-ФЗ** и период с 01.01.2017 по текущую дату. Выполните серию независимых поисков, сохраняя параметры каждого запроса и дату выгрузки.

| Запрос | Поля и ключевые слова |
|---|---|
| Адресный | Климовск + Ленина; Подольск + Ленина; конкретный номер дома |
| Ориентирный | Климовск + Фабрика игрушек; Фабричный проезд; КЛИМО; ДК Машиностроитель |
| Благоустройство | благоустройство, двор, общественная территория, озеленение, содержание территории, освещение, тротуар, пешеходная зона |
| Дорожный | ремонт дороги, асфальт, проезжая часть, ямочный ремонт, тротуар, светофор, дорожные знаки |
| Капремонт | капитальный ремонт, МКД, фасад, кровля, лифт, инженерные системы, внутридомовые сети |
| Коммунальный | теплоснабжение, тепловая энергия, водоснабжение, водоотведение, электроснабжение, сети |
| Организационный | заказчик, управляющая организация, МБУ, МКУ, администрация, МУП, фонд капитального ремонта |

Для каждого найденного результата сохраните реестровый номер закупки, ИКЗ, название, заказчика, НМЦК, способ определения поставщика, дату публикации, регион, место исполнения и прямую ссылку.

## 3. Поиск в реестре контрактов

Повторите поиск по каждому найденному заказчику и по каждому ключевому адресу. В реестре контрактов отдельно проверяйте сведения о заключении, изменениях, исполнении, расторжении, начислении неустоек, оплатах и документах.

Важно связать закупку и контракт по реестровым номерам. Одна закупка может иметь несколько лотов, контрактов, изменений или записей исполнения. Дедупликация выполняется по реестровому номеру контракта, а не по названию.

## 4. Документы, которые следует скачать

Для каждой релевантной процедуры сохраните извещение, документацию, техническое задание, смету или ведомость объёмов, протоколы рассмотрения и подведения итогов, контракт, все изменения, сведения об исполнении, акты, документы о расторжении и решения об одностороннем отказе — если они опубликованы.

Для каждого файла фиксируйте URL, дату скачивания, тип документа, реестровый номер и SHA-256 хэш. Не изменяйте оригиналы; аналитические копии храните отдельно.

## 5. Проверка полноты

Полный массив должен быть получен объединением независимых поисков, а не одной выдачей. После объединения удалите дубли по реестровому номеру закупки и отдельно по реестровому номеру контракта. Составьте журнал исключённых дублей и причин исключения.

Контроль полноты следует проводить по четырём направлениям: адрес, предмет, заказчик и контракт. Если закупка найдена по предмету, но адрес находится только в приложении, она остаётся в рабочем массиве до ручной проверки документации.

## 6. Шаблон CSV

```csv
record_type,procurement_id,contract_id,ikz,published_at,law,customer_name,customer_inn,supplier_name,supplier_inn,subject,okpd2,ktru,nmck,final_price,price_reduction_pct,execution_address,address_match_type,procurement_status,contract_status,termination,document_url,source_query,downloaded_at,sha256,notes
```

`address_match_type` рекомендуется заполнять значениями `название`, `место исполнения`, `техническое задание`, `приложение`, `заказчик`, `ориентир`, `не подтверждено`.

## 7. Что считать релевантным

В основной массив включайте закупки, где адрес улицы Ленина или связанный объект подтверждён в официальном документе. В отдельный слой «контекст» помещайте закупки микрорайона без точного адреса, исторические записи до 2017 года и записи, найденные только в агрегаторе.

Не следует считать подтверждением простое совпадение слова «Климовск», публикацию в СМИ, частный справочник или адрес регистрации компании. Для каждого вывода указывайте первоисточник и уровень подтверждения.

## 8. Запрос к ЕИС при отсутствии массовой выгрузки

Если интерфейс не позволяет сохранить полную выдачу, направьте в поддержку ЕИС запрос с указанием периода, закона 44-ФЗ, территории, всех поисковых формулировок и просьбой сообщить официальный способ получения публичных реестровых номеров и карточек. Просите не закрытые журналы площадки, а публичные данные ЕИС и формат их массового получения.
