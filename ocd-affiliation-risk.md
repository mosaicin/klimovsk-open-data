# ООО «Областной центр дезинфекции»: статусы контрактов и индикаторы аффилированности

**Дата среза:** 15 августа 2026 года. Документ представляет методику проверки открытых данных, а не юридическое заключение.

## Скрипт проверки контрактов

Файл `check_ocd_contracts.py` получает страницы контрактов по ИНН `5021001371`, закону `44-ФЗ` и роли `supplier` через документированный сторонний API-маршрутизатор, сохраняет `contracts.csv`, `contracts.json`, `summary.json`, кэширует страницы ЕИС и ищет в открытом HTML ключевые слова: «расторжение», «односторонний отказ заказчика», «ненадлежащее исполнение», «неустойка» и «уклонение».

Команда запуска:

```bash
export OFDATA_API_KEY='ваш_ключ'
python3 check_ocd_contracts.py --out data/ocd_44fz --fetch-eis
```

Скрипт не считает совпадение ключевого слова доказательством нарушения. Каждая строка срабатывания требует ручной проверки карточки ЕИС, протокола, документа об исполнении, уведомления об одностороннем отказе и, при наличии, судебного акта. API Ofdata — не официальный API ЕИС; он требует собственного ключа и используется только как машиночитаемый источник, после чего ссылки на карточки нужно сверять с ЕИС [1] [2].

## Оценка риска

На текущем объёме данных **признаки аффилированности с московским заказчиком не установлены**. Это не означает, что аффилированности не существует: полная проверка требует всех 232 строк, ЕГРЮЛ-профилей каждого заказчика, исторических руководителей и учредителей, контактных данных, протоколов закупок и файлов заявок.

Из общедоступных корпоративных совпадений ранее подтверждалась связь самого ОЦД с ООО «ОЦД-МАРКЕТ» и ООО «ВЕЗУРЕКЛАМУ.РУ» через Дмитрия Кутьева, но это связь поставщика с другими юридическими лицами, а не с заказчиком из московской карточки. Наличие общего адреса у частных компаний также не доказывает связь с государственным заказчиком.

Для усиленной проверки следует построить матрицу `ОЦД — заказчик — руководитель — учредитель — адрес — телефон — участники — контракт — статус`. Любое совпадение нужно подтверждать минимум двумя независимыми источниками и не трактовать как нарушение без решения ФАС или суда.
